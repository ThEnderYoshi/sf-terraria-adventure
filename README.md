# ![Sans Fanfic: Terraria Adventure](.github/images/gh-logo.png)

<span style="color:red">Sans Fanfic</span>: Terraria Adventure (SFTA) is a
[_Terraria_] [Resource Pack] that aims to change _**every single**_ asset in the
game to be themed around <span style="color:red">[_Sans Fanfic_]</span>.

That mainly includes the game's

### "Where is the player model?"

While the actual `Player_*` sprites are complete, most of the hair, armor,
accessories, etc. are not. This means the visuals really clash, so the player
model will only be brought to the main pack when most of its sprites are done.

Currently, the player model as well as the equipped GFX for added
armors/accessories are in a separate Resource Pack, but I'm not sure it'll be
made public.
